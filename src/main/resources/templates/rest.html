RESTful API

Az alkalmazás a mozik adatait JSON formátumban teszi elérhetővé. Az olvasás mindenkinek nyitott, a módosításhoz admin felhasználó szükséges (HTTP Basic hitelesítés).

MetódusURLLeírásJogosultság
GET/api/mozikAz összes mozi listázásanyitott
GET/api/mozik/{id}Egy mozi lekérésenyitott
POST/api/mozikÚj mozi felvétele (JSON törzs)admin
PUT/api/mozik/{id}Mozi módosítása (JSON törzs)admin
DELETE/api/mozik/{id}Mozi törléseadmin

Próbálja ki: /api/mozik, /api/mozik/1

Példa JSON törzs

{"nev": "Teszt Mozi", "varos": "Szolnok", "ferohely": 120}
